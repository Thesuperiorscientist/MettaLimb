# Implementation timeline

From a Myanmar pilot to an ASEAN-scale model. All items are planned.

| Phase | When | Theme |
|---|---|---|
| 1. Validate | Months 0-3 | From waste potential to working materials |
| 2. Pilot | Months 4-6 | From prototype to real-world testing |
| 3. Optimize | Months 7-12 | From learning to a stronger model |
| 4. Scale | Year 2 onward | From local impact to regional change |

## Phase 1: Validate (months 0-3)
- [ ] Research and material testing (PET to filament)
- [ ] Prototype development
- [ ] Initial design validation
- [ ] Engage stakeholders: healthcare, partners, waste suppliers, local community

## Phase 2: Pilot (months 4-6)
- [ ] Launch the pilot in Myanmar, the highest-potential country
- [ ] Set up collection and sorting
- [ ] Produce initial prosthetic components
- [ ] Test with local patients
- [ ] Collect feedback for improvement

## Phase 3: Optimize (months 7-12)
- [ ] Improve the design based on user feedback
- [ ] Strengthen quality control
- [ ] Increase production capacity
- [ ] Expand the waste collection network
- [ ] Measure environmental and social outcomes
- [ ] Prepare for regional expansion

## Phase 4: Scale (year 2 onward)
- [ ] Expand to other ASEAN countries
- [ ] Establish local processing hubs
- [ ] Build partnerships with government, NGOs and healthcare
- [ ] Scale manufacturing and distribution
- [ ] Increase community outreach
- [ ] Build long-term sustainability and impact

Tick items off and add dates as the project moves forward.
