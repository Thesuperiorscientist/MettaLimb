# Presentation

Add the pitch deck here as a PDF (for example `MettaLimb_Data_Alchemists.pdf`). GitHub shows PDFs directly in the browser.

Tips:
- Export the PDF from the original design tool so fonts and images look right
- Keep it under about 25 MB if you upload through the web page (git itself allows up to 100 MB per file)
- Check you have the right to share every image in the deck
- Check any competition or programme rules about publishing before making the repository public
- Link the PDF from the main README once it is added
